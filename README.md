# Network Visualization Platform

منصة ويب تفاعلية لعرض تصور بصري للشبكات والعُقد والروابط بينها.

## نظرة عامة

يحتوي المستودع على صفحة ويب مستقلة باسم `index (6).html`. يمكن فتحها مباشرة في المتصفح أو تشغيلها من خلال خادم محلي بسيط.

## التقنيات
- HTML
- CSS
- JavaScript

## تشغيل المشروع محلياً

```bash
git clone https://github.com/helx0/network-.git
cd network-
python -m http.server 8000
```

افتح `http://localhost:8000/index%20(6).html` في المتصفح، أو افتح الملف مباشرة.
